# Assets/Icons

Сюда кладутся PNG-иконки предметов: `{item_id}.png` или `{icon_key}.png` (см. `Data/items_ds1.json`).
Оригинальные иконки Dark Souls не распространяются с приложением — см. раздел «Иконки» в корневом README
и скрипт `Scripts/fetch_icons.py`. Если файла нет, приложение рисует векторную иконку категории.
