# Assets/Icons

PNG-иконки предметов лежат по папкам игр: `ds1/{id}.png`, `ds2/{id}.png` и т. д.
(`id` и `icon_key` — из `Data/{игра}/items.json`). Файл в корне `Assets/Icons/` используется как общий запасной.

Оригинальные иконки игр не распространяются с приложением. Скачать их на свой ПК:
`python Scripts/fetch_icons.py --game ds1 --wiki` (или `--game ds2`). Без файла рисуется векторная иконка категории.
